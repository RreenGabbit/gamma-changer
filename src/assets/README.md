# Flashbang icon

`flashbang.png` is the original Counter-Strike flashbang inventory image downloaded
from [Valve's Steam CDN](https://cdn.steamstatic.com/apps/730/icons/econ/weapons/base_weapons/weapon_flashbang.bbde1307eeb99d78ef67c3a87a3a713023b63af2.png).
The artwork belongs to Valve.

`flashbang.ico` packages the artwork with transparency at 16, 20, 24, 32, 40, 48,
64, 128, and 256 pixels. Transparent margins are trimmed and the image is centered
on a square canvas without changing its proportions. No image generation was used.

The PNG is retained as the source asset; application builds embed the ICO and do
not need to download or convert images.
