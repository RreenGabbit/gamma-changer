# Flashbang icon

`flashbang.png` is the flashbang image downloaded from the
[RustClash Wiki URL supplied for this project](https://wiki.rustclash.com/img/items180/grenade.flashbang.png).

`flashbang.ico` packages the artwork with transparency at 16, 20, 24, 32, 40, 48,
64, 128, and 256 pixels. The square source image is resized without changing its
proportions. No image generation was used.

The PNG is retained as the source asset; application builds embed the ICO and do
not need to download or convert images.
